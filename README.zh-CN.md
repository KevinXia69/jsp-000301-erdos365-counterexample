# 中文说明

本包形式化的是 **JSP-000301 / Erdős 第365题的第一问**：

> 任意两个相邻的正强数中，是否至少有一个是完全平方数？

Lean 证明给出 Golomb 的明确反例：

- `12167 = 23^3`
- `12168 = 2^3 · 3^2 · 13^2`

两者都是强数；同时它们都位于 `110^2 = 12100` 与
`111^2 = 12321` 之间，所以都不是平方数。

核心文件为 `Erdos365Counterexample.lean`。构建命令：

```bash
lake update
lake build
```

注意事项：

1. 这只否定第一问，不解决该 Erdős 问题仍然开放的计数问题。
2. 数学反例归功于 Solomon W. Golomb。
3. Formal Conjectures 现有代码已经在另一条定理中核验了该数对的
   3-full/2-full 性质；本包新增的是两个非平方证书及对第一问的完整逻辑包装。
4. 奖项资格、优先权和奖金均须由主办方独立核验，不能仅凭成功编译推定。
